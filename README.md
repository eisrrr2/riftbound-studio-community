# Riftbound Studio

리프트바운드 한국어 덱 빌더·카드 보드형 리플레이·봇 대전·AI 전략 연구 프로젝트입니다.

## 초대 테스트

**[홈페이지 열기](https://eisrrr2.github.io/riftbound-studio-community/)** → 초대 테스트 입장 → 개발자에게 받은 초대 코드로 로그인하세요.
실제 Studio V3 사람 vs 봇 대전, V2/V3 자동 대전 4~20판 및 해당 경기의 보드 리플레이를 제공합니다.
PC가 켜져 있을 때만 이용할 수 있는 임시 주소이며, 동시 작업은 1개입니다. 자동 대전은 좌석 교환을 포함합니다.
초대 코드를 공개 Issue에 적지 마세요. 운영자가 링크를 다시 열 때까지 접속되지 않을 수 있습니다.

## 여러분의 플레이로 더 나은 AI를 함께 만들어 주세요

제공 권한이 있는 실제 인간 대 인간 경기 기록을 보내주시면, 형식·규칙·정보 누수를 검증한 뒤 AI 행동 학습과 전략 평가 연구에 활용합니다.
모든 제출 자료가 학습되거나 성능 향상이 보장되는 것은 아닙니다.

- **권장 자료:** SimKR 원본 `.rbr` + 같은 경기의 `.actions.json`; 운영자 내보내기는 동일 버전 `cards.csv`도 포함.
- **제공 절차:** [파일 형식·제공 권한·비공개 전달 안내](CONTRIBUTE_REPLAYS.md)를 읽고 [Issue](https://github.com/eisrrr2/riftbound-studio-community/issues/new)로 파일 없이 문의하세요.
- **주의:** 원본 기보·개인 정보·비공개 손패·가중치를 Issue/PR/공개 링크에 올리지 마세요.
- 다른 서비스 형식은 사전 호환성·이용 권한 검토가 필요합니다. 자동 접수·범용 변환기는 아직 제공하지 않습니다.

## 현재 AI

운영 추천은 **Studio V3**입니다. V2의 학습 가중치를 유지하고 전술 평가·효과 완료 후 평가·검색 동률 선택을 개선했습니다.
전설 16종·136개 덱 조합의 내부 V2 비교에서 조건별 1,632판을 수행했습니다.

| 조건 | V3 승 / 패 / 미종료 | 종료 경기 승점률 |
|---|---:|---:|
| 양쪽 탐색 24회 | 1,127 / 500 / 5 | 69.27% |
| 양쪽 소프트 시간 상한 8ms | 1,058 / 569 / 5 | 65.03% |

미종료는 무승부로 바꾸지 않고 불확실성에 반영했습니다. 알려진 OGN/OGS 덱·금지 카드 허용 내부 평가이며 인간·외부 봇·대회 상대 실력을 증명하지 않습니다.

## 공개 범위

이 저장소는 소개와 데이터 제공 안내용입니다. 엔진 소스·AI 내부 구현·가중치·연구용 원본 및 가공 기보는 포함하지 않습니다.
개발 저장소는 비공개로 관리하며, 온라인 체험은 초대 코드가 필요한 소규모 임시 테스트이며, 공개 엔진 API·다운로드용 모델은 제공하지 않습니다.
플레이 자료 제출만으로 모델 재배포나 외부 서비스 제공에 동의한 것으로 간주하지 않습니다.

Studio Engine은 [AlphaRune](https://github.com/chorlick/alpharune)에서 출발한 파생 프로젝트이며 원본 출처와 해당 라이선스·권리 고지를 존중합니다.
Riftbound 및 카드 이미지의 권리는 각 권리자에게 있습니다. 이 프로젝트는 공식 운영 서비스가 아닙니다.
